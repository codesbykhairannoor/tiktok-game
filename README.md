# TikTok LIVE Interactive Games Studio

Koleksi game interaktif TikTok LIVE otomatis berbasis Node.js & WebSocket:

---

## 1. Kuis Cerdas Cermat Anak SD (RupaGames Style) 🎒
- **Folder:** `d:\livetiktok\gameanak_sd\`
- **Port:** `3002`
- **Tampilan OBS:** `http://localhost:3002`
- **Panel Streamer:** `http://localhost:3002/streamer`
- **Cara Menjalankan:** Klik ganda file `start_game_sd.bat` di root atau di dalam folder `gameanak_sd/start.bat`
- **Fitur Unggulan:**
  - Desain identik 100% RupaGames (Pastel Sky Blue, Neo-Pop Doodle, 1080x1920)
  - 12 Kategori Lengkap & 120 Soal Anak SD
  - Area Bawah Dikosongkan (~600px) Khusus Kolom Komentar & Chat TikTok LIVE
  - Pemenang Tercepat per Soal (`TERCEPAT / @username - X.XX dtk • +100 Pts`)
  - Papan Skor Ganda (Poin Ronde Ini vs Poin Total LIVE)
  - Layar Podium Akbar Akhir Ronde (`JUARA RONDE.`)
